# mini-CEX.tw.entrust 教學評估數據管理平台

臨床教學評量數據彙整與統計平台的設計原型，涵蓋 mini-CEX 信賴授權評量的多維度分析、分層權限儀表板與教學回饋工具。

> **這是設計原型，不是可上線的系統。** 所有人名、員工編號、機構名稱與評量內容均為虛構，不代表任何真實評量結果或個人資料。

## 線上展示

啟用 GitHub Pages 後，網址為 `https://<你的帳號>.github.io/<儲存庫名稱>/`

## 功能範圍

### 角色權限（RBAC）

| 角色 | 可檢視範圍 | 主要功能 |
| --- | --- | --- |
| 學員 | 自己被評量的資料 | 個人評量、我的成績、單筆 PDF 下載 |
| 教師 | 自己評量過的資料 | 個人評量、本科實習學員、回饋撰寫助手 |
| 科部行政承辦人 | 負責科部含次專科 | 科部儀表板、資料匯出 |
| 科部教學推動人 | 負責科部含次專科 | 科部儀表板、資料匯出 |
| 全院型主管 | 全院所有科部 | 全院儀表板、資料匯出 |
| 系統管理者 | 全系統 | 帳號權限、承辦人指派、排程與配分表上傳、稽核軌跡、內容擴增 |

一人可同時具備多種角色，登入後可在側邊欄即時切換。

### 主要頁面

- 前台：Landing page、個人評量（信賴授權矩陣、七構面雷達圖、學習進度、質性回饋、引導思考、學習歷程）、我的成績、學習資源
- 後台：科部與全院儀表板（含次專科下鑽、逾期升級規則、洞察聚類）、資料匯出、帳號管理、內容擴增
- 通用：側邊欄、header、footer、個人資料頁、每頁回到首頁按鈕、中英雙語切換

### AI 功能

三處使用大型語言模型，全部經過去識別化前置過濾：

1. **洞察聚類** — 從質性回饋歸納常見好表現與待改進處
2. **學習建議** — 交叉比對各科成績與 mini-CEX 回饋產出建議
3. **回饋撰寫助手** — 檢查教師回饋草稿的具體程度並提供改寫

### 去識別化

送往模型前自動遮蔽九類可識別資訊：身分證號、電子郵件、電話、病歷號、員工編號、床號、人名、完整日期、地址。過濾寫在 API 封裝層，任何呼叫都無法繞過。

此為送出前的最後一道過濾，正式系統仍須在表單填寫階段就攔截，並搭配詞典比對或命名實體辨識作為第二道。

## 部署

### 靜態託管（GitHub Pages、Netlify、Vercel）

直接部署 `index.html` 即可。這是單一檔案，所有 CSS 與 JavaScript 都已內嵌，不需建置流程。

GitHub Pages 設定方式：儲存庫 Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` 與 `/ (root)`。

`.nojekyll` 檔案用於停用 Jekyll 處理，請一併保留。

**靜態託管下 AI 功能不可用。** 瀏覽器端不能存放 API 金鑰，因此在偵測到靜態託管環境時，AI 按鈕會自動停用並顯示「靜態展示版」，其餘功能完全不受影響。

### 啟用 AI 功能

需自建後端代理保管 API 金鑰。後端接收前端請求，附上金鑰後轉發至 Anthropic API，再把回應傳回。

部署後在 `index.html` 的 `<head>` 中設定代理位址：

```html
<script>
  window.__AI_PROXY__ = "https://your-api.example.com/ai";
</script>
```

後端代理的最小職責：驗證呼叫者身分、附加 `x-api-key` 與 `anthropic-version` 標頭、限制呼叫頻率、記錄呼叫紀錄。

## 技術

React 18、TypeScript、Tailwind CSS、Recharts、lucide-react。以 Parcel 打包並內嵌為單一 HTML 檔。

## 已知限制

- 所有資料為前端寫死的示範資料，沒有後端與資料庫
- 權限過濾僅在前端，正式系統必須在後端查詢層再做一次
- 中文姓名的去識別化偵測不完備，無稱謂與前綴的裸姓名無法攔截
- 次專科權重目前為固定比例，實際計算方式待配分表確認
- 密碼重設、檔案上傳、PDF 下載、Excel 匯出皆為示範互動，未實際執行
